## Built this round: the 10-project limit and honest headings

| Rule | How |
|---|---|
| A category leaderboard shows at most 10 ranked projects | `investment_index.public_leaderboard_size = 10`, applied in the leaderboard query |
| A city filter, search filter or pagination never shows a position beyond 10 | The query keeps `category_rank <= 10` whatever the filter. Lower-ranked projects appear in the "assessed, not ranked" list without a position |
| Project pages and comparison | A rank beyond 10 shows as "Ranked, outside the published top 10" |
| The AI assistant | Quotes only published top-10 positions |
| Overall Index | Also limited to 10 |
| Headings | "Top 10 Verified Housing Societies" only when ten qualify; "Verified Housing Society Rankings" for one to nine; the plain category name for none |
| Per category, not global | Up to 50 across the five categories |
| History | Unchanged. All ranks stay in the stored runs and in admin |
